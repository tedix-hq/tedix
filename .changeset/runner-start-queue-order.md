A runner's waiting starts keep their order. A start a person asked for takes a fourth preparation place; the next preparation to end then woke the oldest waiting start although no place was free, and that start went to the back of the order. A freed place now goes straight to the oldest waiting start, however the preparation ended. A start request for an item that is waiting starts it at once instead of being skipped as "Already running here", and a waiting start whose Work changed or left the runner's list is dropped and no longer counts as running.
