# @tedix/webmcp-core

WebMCP primitives for exposing browser-side tools to agents: a tool registry,
the page bridge script, model-context assembly, and portable capability
profiles. Tedix OS uses it so that an agent working in the browser sees the
same tool surface a person does.

Runtime-neutral and framework-free. Tests run with `bun run test:run`.
