# Credits, plans and usage

Tedix Cloud measures all usage in Tedix credits. You can see how many credits
your organization has used this month, buy more when you need them, and set
monthly caps so one tedi or one person cannot use them all. To start, open
**Billing** in Tedix OS and choose the **Usage** tab. Only organization owners
can open Billing.

Tedix Cloud is an invited beta. See [Release status](./release-status.md) for
what is available today.

## What a credit is

1 credit = €0.01. A credit pack of 1,000 credits costs €10.

Credits are the only unit you see and the only thing you are limited by. Every
limit is monthly; there are no daily limits.

## What uses credits

Three kinds of work use credits from the same monthly balance:

| What      | How many credits                                                                                                                                                         |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| AI        | Each reply or step a tedi or Home writes uses credits. Longer and more complex work uses more. The number is worked out for every call and rounded up to a whole credit. |
| Code runs | 1 credit for each run of code that an agent starts, for example a script it runs to work with your tools or data.                                                        |
| Services  | Some tools charge a fixed number of credits each time they run, for example an SEO check. The tool tells you its price.                                                  |

Billing shows how many credits each of these used this month.

## What each plan includes

Every plan includes a number of credits each month.

| Plan       | Price                                  | Credits included each month          |
| ---------- | -------------------------------------- | ------------------------------------ |
| Starter    | Free                                   | 500                                  |
| Growth     | €200 a month                           | 15,000                               |
| Business   | €500 a month                           | 40,000                               |
| Enterprise | From €1,000 a month, set in a contract | 100,000 by default, set per contract |

Included credits renew at the start of each billing month. Credits you did not
use do not carry over to the next month.

## Buy credit packs

If you need more credits, buy a credit pack in **Billing → Usage → Buy credit
packs**. Packs are one-time purchases:

| Pack           | Price |
| -------------- | ----- |
| 1,000 credits  | €10   |
| 5,000 credits  | €50   |
| 10,000 credits | €100  |
| 25,000 credits | €250  |
| 50,000 credits | €500  |

Pack credits last 12 months from the day you buy them. Tedix uses your plan's
included credits first, then your pack credits, starting with the ones that
expire soonest.

## Notices at 80% and 100%

Tedix tells you once each month when your organization has used 80% of its
included credits, and again at 100%. You see the notice at the top of
**Billing → Usage**.

## What happens when credits run out

When the included credits and pack credits are used up, new work that uses
credits stops. Work starts again when:

- the included credits renew at the start of the next billing month,
- an owner buys a credit pack, or
- an owner turns on pay-as-you-go.

## Pay-as-you-go with a monthly cap

Pay-as-you-go is off by default. When it is on, your tedis keep working after
your credits run out, and the extra credits cost €0.01 each.

To turn it on:

1. Open **Billing** and choose the **Subscription** tab.
2. Under **Pay-as-you-go**, turn on **Keep working past my credits**.
3. Enter a monthly cap in euros, for example €50. That allows up to 5,000
   extra credits a month.
4. Choose **Save**.

You are never charged more than the cap in a month. When the cap is reached,
new work stops until the next month, or until you raise the cap or buy a
credit pack.

## Caps for each tedi and member

**Billing → Usage → Usage by tedi and member** shows how many credits each
tedi and each member used this month. An owner can set a monthly cap for any
of them:

1. Find the tedi or member.
2. Enter the cap in credits, for example 2,000.
3. Choose **Save**.

When a tedi reaches its cap, that tedi pauses until next month; your other
tedis keep working. When a member reaches their cap, work they start pauses
until next month. Leave the field empty to remove the cap.

A cap can only lower what one tedi or person may use. It never adds credits to
your organization, and it cannot be higher than your organization's credits
for the month. Only Tedix can change the number of credits included in an
Enterprise contract.

## Where else you see credits

Outside **Billing › Usage**, Tedix shows usage as a percentage of this month's
credits: your plan's included credits plus any credit-pack credits for the
month. For example, "23% used this month". Exact credit counts appear only on
the Billing › Usage page.

- **Usage** in the account menu shows the percentage used this month.
- The **Usage** page shows the percentage used this month and every monthly
  limit with how much of it is used.
- Home shows what share of this month's credits each conversation used once
  its work is finished. You see it if you can view billing.
